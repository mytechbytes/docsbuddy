# Play Store listing assets

**To apply the original logo file (preferred):** drop it in the repo as
`assets/icon/source_logo.png` (any size; transparent or plain background),
then from the repo root:

```sh
pip install pillow numpy
python3 tool/apply_brand_icon.py     # derives ALL assets from the exact pixels
dart run flutter_launcher_icons      # regenerates Android mipmaps + iOS AppIcon
```

`apply_brand_icon.py` never redraws the mark — it only trims, removes a
uniform background if the file has none, resizes and pads. The current
assets were generated by `tool/make_brand_assets.py`, a programmatic
recreation of the mark, and stand only until the original file is dropped in.

| File | Play Console slot |
|------|-------------------|
| `play_icon_512.png` | App icon (512×512, 32-bit PNG) |
| `feature_graphic_1024x500.png` | Feature graphic (1024×500) |
| `splash_mark.png` | spare padded mark (branded splash / misc) |
